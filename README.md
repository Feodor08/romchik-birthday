# Дело № 23 — сайт-поздравление

Статический сайт без сборки и зависимостей. Видео уже скопированы в `videos/` по папкам поздравляющих и подключены в `script.js`. Изображение `videos/images.jpg` перенесено из исходной папки, но на странице пока не используется.

## Важно про публикацию видео

Все видео занимают около 1,8 ГБ. Ролики Денчика превышают 100 МБ, также секретное видео около 138 МБ; GitHub не принимает обычные файлы больше 100 МБ. Сайт можно открыть локально, но прежде чем публиковать его, уменьшите эти ролики или разместите видео на видеохостинге и замените адреса в `script.js` на ссылки, доступные посетителям. Не загружайте такие оригиналы в обычный GitHub-репозиторий.

## Видео по поздравляющим

Каждая карточка показывает плееры для всех видео человека. Файлы лежат в `videos/Диман`, `videos/Денчик`, `videos/Данич`, `videos/Олег` и `videos/Федя`. Если вы замените файлы, оставьте их имена или обновите соответствующие пути в массиве `videos` в `script.js`.

После Феди размещена карточка «СОВЕРШЕННО СЕКРЕТНО». Подсказка ведёт к слову `стриптиз`; после ввода открывается `videos/СЕКРЕТНО.mp4`. Это скрывает видео только в интерфейсе: пароль проверяется в JavaScript на стороне браузера и не является защитой от технически подкованного посетителя.

Для загрузки в репозиторий каждый файл должен быть меньше 100 МБ, однако даже меньшие видео удобнее размещать на видеохостинге, чтобы посетителям не приходилось скачивать большой репозиторий.

```js
if (friend.video) {
  videoSlot.innerHTML = `<video class="greeting-video" controls playsinline preload="metadata"><source src="${friend.video}" type="video/mp4">Ваш браузер не поддерживает видео.</video>`;
} else {
  videoSlot.innerHTML = `<div class="video-placeholder"><div><strong>▶</strong><p>Видео-поздравление от ${friend.name}<br>появится здесь перед публикацией сайта.</p></div></div>`;
}
```

Можно загрузить и вертикальные MP4 — плеер подстроится к пропорциям, если добавить в `styles.css` правило `.greeting-video{width:100%;max-height:70vh;background:#000}`. Для больших файлов сначала сожмите видео: GitHub ограничивает размер обычных файлов в репозитории.

## Опубликовать через GitHub Pages

1. Создайте на GitHub новый публичный репозиторий, например `romchik-birthday`.
2. Загрузите в него содержимое этой папки: `index.html`, `styles.css`, `script.js`, `README.md` и, после добавления, `videos`.
3. Откройте репозиторий → **Settings** → **Pages**.
4. В **Build and deployment** выберите **Deploy from a branch**, ветку `main` и папку `/ (root)`, затем нажмите **Save**.
5. Дождитесь публикации и откройте показанный GitHub Pages адрес вида `https://ВАШ-ЛОГИН.github.io/romchik-birthday/`.
6. Проверьте сайт по этой ссылке с телефона до создания QR-кода. После каждого обновления файлов GitHub Pages опубликует изменения автоматически.

## Создать QR-код

Сначала опубликуйте сайт и возьмите его полный HTTPS-адрес GitHub Pages. На компьютере с Python установите библиотеку командой `py -m pip install qrcode[pil]`, затем выполните в папке проекта:

```powershell
py -c "import qrcode; qrcode.make('https://ВАШ-ЛОГИН.github.io/romchik-birthday/').save('romchik-qr.png')"
```

Замените адрес на фактический. Получившийся `romchik-qr.png` можно отправить в печать. Перед печатью проверьте код камерой телефона и убедитесь, что он ведёт на открывающуюся страницу.
